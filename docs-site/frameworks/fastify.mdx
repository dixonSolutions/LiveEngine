This example keeps matchmaking state in a hub process and calls it over HTTP. It works across multiple Fastify instances, containers, and languages.

## Install and run

Start a hub first:

```sh
export LIVEENGINE_TOKEN="$(openssl rand -hex 32)"
LIVEENGINE_BIND=127.0.0.1:8787 liveengine-hub &
```

Then run the API:

```sh
npm install fastify @dixonsolutions/liveengine

LIVEENGINE_URL=http://127.0.0.1:8787 \
LIVEENGINE_TOKEN="$LIVEENGINE_TOKEN" \
LIVEENGINE_HUB_ID=ranked \
node examples/frameworks/fastify-server.mjs
```

The hub ID must exist in the hub registry. Create it once with `HubClient.register`; see [Hosting](/guides/hosting).

## Server

```js
import Fastify from 'fastify';
import { HubClient } from '@dixonsolutions/liveengine/hubs';

const hubUrl = process.env.LIVEENGINE_URL;
const token = process.env.LIVEENGINE_TOKEN;
const hubId = process.env.LIVEENGINE_HUB_ID || 'ranked';

if (!hubUrl || !token) {
  throw new Error('Set LIVEENGINE_URL and LIVEENGINE_TOKEN');
}

const app = Fastify({ logger: true });
const hub = new HubClient(hubUrl, { token, timeoutMs: 10_000 });
await hub.contract();

app.get('/api/health', async () => ({ app: 'ok', hub: await hub.contract() }));

app.post('/api/servers', async (request, reply) => {
  const { id, capacity = 2, minMembers = 0, scopes = {}, requirements } = request.body || {};
  if (!id) return reply.code(400).send({ error: 'id is required' });
  const result = await hub.call(hubId, 'upsertServer', [
    { id, capacity, minMembers, scopes, requirements },
  ]);
  return { id, created: result };
});

app.post('/api/match', async (request, reply) => {
  const { userId, scopes = {}, requirements } = request.body || {};
  if (!userId) return reply.code(400).send({ error: 'userId is required' });
  await hub.call(hubId, 'upsertUser', [{ id: userId, scopes, requirements }]);
  const result = await hub.call(hubId, 'autoJoin', [userId]);
  if (!result.ok) return reply.code(409).send(result);
  const server = await hub.call(hubId, 'getServer', [result.serverId]);
  return { ...result, server };
});

app.get('/api/stats', async () => hub.call(hubId, 'stats'));

const port = Number(process.env.PORT || 3001);
await app.listen({ port, host: '127.0.0.1' });
```

## What to handle in production

- **Create the hub at deploy time or lazily.** `HubClient.register` returns `409` if the ID already exists. Treat that as success, or check `get` first.
- **Keep the token server-side.** Never put `LIVEENGINE_TOKEN` in browser bundles or URLs.
- **Map hub errors.** A `HubClient` rejection has a `status` property. Return `409` for `ok: false` engine results and `502` or `503` for upstream failures.
- **Set client limits.** `timeoutMs` defaults to 5 seconds and `maxResponseBytes` defaults to 1 MiB; both are configurable in the constructor.
- **Do not trust player IDs.** Authenticate the request in Fastify and derive `userId`; LiveEngine authorizes administrators, not players.
