LiveEngine has two integration shapes. Pick the one that matches where your state lives.

| Shape | Use it when | State |
| --- | --- | --- |
| In-process `LiveEngine` | One Node or Rust process owns matchmaking | In that process |
| `HubClient` to a hub | Multiple instances or languages need one registry | In the hub process |
| Embedded `HubService` | A Rust API already owns the Axum router | In that API process |
| Standalone `liveengine-hub` | You want a separate central registry or remote service | In the hub process |

<Warning>
  In-process engines are process-local. Two web instances with their own `LiveEngine` will not see each other's users or servers. For horizontal scaling, point every instance at one central hub with `HubClient`, or run one hub per matchmaking shard.
</Warning>
