`HubClient` talks to any host that implements `liveengine.hub/v1`. It has no native dependency and is available from both the package root and the `hubs` subpath.

```js
const { HubClient, HUB_PROTOCOL } = require('@dixonsolutions/liveengine/hubs');
```

## Constructor

```ts fragment
interface HubClientOptions {
  token: string;
  timeoutMs?: number;          // default 5000
  maxResponseBytes?: number;   // default 1048576 (1 MiB)
  fetch?: typeof globalThis.fetch;
}

new HubClient(address: string, options: HubClientOptions);
```

```js
const client = new HubClient('https://hub.example.net', {
  token: process.env.LIVEENGINE_TOKEN,
  timeoutMs: 10_000,
  maxResponseBytes: 2 * 1024 * 1024,
});
```

Constructor validation:

- `address` must be an absolute `http:` or `https:` base URL.
- It must not contain a username, password, query, or fragment.
- A trailing slash is removed from `client.address`.
- `token` must be a non-empty string.
- `timeoutMs` must be finite and at least `1`.
- `maxResponseBytes` must be a safe integer at least `1`.

Violations throw `TypeError`. The token is stored in a non-enumerable property and is not visible in `JSON.stringify(client)`.

## Request behavior

Every request:

- sends `Authorization: Bearer <token>` and `Content-Type: application/json`
- uses `redirect: 'error'`
- enforces `timeoutMs` with an abort signal
- caps the response body at `maxResponseBytes`
- parses JSON; an empty body becomes `null`
- throws on invalid JSON with `Hub returned invalid JSON (HTTP <status>)`
- throws on a non-2xx status with the server's `error` message when present, otherwise `Hub request failed (HTTP <status>)`; the thrown error has a numeric `.status`

An optional `AbortSignal` can be passed to `call` and is combined with the timeout.

## Methods

### contract()

```ts fragment
contract(): Promise<{ protocol: 'liveengine.hub/v1'; [key: string]: unknown }>
```

Calls `GET /v1/contract`. Throws `Incompatible hub protocol` unless the response `protocol` is `liveengine.hub/v1`.

```js
await client.contract();
```

### ping(options?)

```ts fragment
interface HubPingOptions {
  samples?: number;   // 1–32, default 5
  intervalMs?: number; // default 0
}

interface HubPing {
  protocol: 'liveengine.hub/v1';
  samples: number[];
  minMs: number;
  maxMs: number;
  avgMs: number;
  jitterMs: number;
  serverTimeMs?: number;
}

ping(options?: HubPingOptions): Promise<HubPing>
```

Calls the unauthenticated native `GET /v1/ping` endpoint repeatedly and measures round-trip time with the high-resolution clock. `jitterMs` is the mean absolute difference between consecutive samples.

```js
const result = await client.ping({ samples: 5, intervalMs: 50 });
console.log(result.avgMs, result.minMs, result.maxMs, result.jitterMs);
```

### list()

```ts fragment
list(): Promise<{ hubs: HubInfo[] }>
```

Calls `GET /v1/hubs`.

```js
const { hubs } = await client.list();
```

### register(hub)

```ts fragment
register(hub: HubDefinition): Promise<HubInfo>
```

Calls `POST /v1/hubs` and returns the created public metadata (`201`).

```js
const info = await client.register({
  id: 'ranked-au',
  mode: 'internal',
  scopes: { game: 'chess', region: 'au' },
});
```

`HubDefinition`:

```ts
interface HubDefinition {
  id: string;
  mode: 'internal' | 'external' | 'central';
  address?: string;
  remoteHubId?: string;
  remoteToken?: string;
  scopes?: Record<string, unknown>;
  scopeSchema?: Record<string, unknown> | boolean;
  ttlSeconds?: number;
  // Nesting, schemas, live and auth fields. See the guides linked below.
  template?: string;
  ifAbsent?: boolean;
  schemaRef?: string;
  userSchema?: Record<string, unknown> | boolean;
  serverSchema?: Record<string, unknown> | boolean;
  channels?: Record<string, { schemaRef?: string; delivery: 'reliable' | 'lossy'; maxRate?: number }>;
  auth?: HubAuth;                 // token, hmac, jwt, webhook or custom
  hosting?: 'provider';           // central hubs only
  maxHubs?: number;               // central hubs only
  liveDepth?: number;             // central hubs only
}
```

The client does not validate the DTO beyond serialization; the host returns `400` with a message for an invalid registration.

### get(id)

```ts fragment
get(id: string): Promise<HubInfo>
```

Calls `GET /v1/hubs/{id}`. The ID is URL-encoded. A missing hub throws with `.status === 404`.

### remove(id)

```ts fragment
remove(id: string): Promise<null>
```

Calls `DELETE /v1/hubs/{id}`. A successful delete returns `204` with no body, so the resolved value is `null`. A missing hub throws with `.status === 404`.

### call(id, method, args?, options?)

```ts fragment
call<T = unknown>(
  id: string,
  method: string,
  args?: unknown[],
  options?: { signal?: AbortSignal },
): Promise<T>
```

Calls `POST /v1/hubs/{id}/call` with `{ method, args }` and resolves the **unwrapped `result` field**.

```js
const pair = await client.call('ranked-au', 'autoJoin', ['alice']);
if (pair.ok) {
  console.log('joined', pair.serverId);
}

const stats = await client.call('ranked-au', 'stats');

const controller = new AbortController();
const events = await client.call('ranked-au', 'drainEvents', [], {
  signal: controller.signal,
});
```

`args` defaults to `[]` and must be an array; otherwise `call` throws `TypeError: args must be an array`. Method names are validated by the host (`1–128` bytes).

### importRegistry(registry)

```ts fragment
importRegistry(registry: {
  address: string;
  token: string;
  prefix?: string;
}): Promise<{ hubs: HubInfo[] }>
```

Calls `POST /v1/registries/import` and returns the imported public records.

```js
await client.importRegistry({
  address: 'https://remote.example.net',
  token: process.env.REMOTE_HUB_TOKEN,
  prefix: 'partner-',
});
```

## Accounts and sessions

These call the [account and session routes](/guides/accounts-and-sessions). The token the client was built with decides what is allowed: the administrator token or an `admin` session can manage accounts; a `user` session can only use `me`, `logout`, `changePassword` and `getAccount` for itself.

```ts fragment
interface Account { username: string; role: 'admin' | 'user'; enabled: boolean; claims?: Record<string, unknown>; createdAt: number; }

login(username: string, password: string): Promise<{ token: string; account: Account; expiresAt: number }>
logout(): Promise<null>
me(): Promise<Account>
changePassword(current: string, next: string): Promise<null>
listAccounts(): Promise<Account[]>
createAccount(account: { username: string; password: string; role: 'admin' | 'user'; enabled?: boolean; claims?: Record<string, unknown> }): Promise<Account>
getAccount(username: string): Promise<Account>
updateAccount(username: string, changes: { role?: 'admin' | 'user'; enabled?: boolean; claims?: Record<string, unknown> | null; password?: string }): Promise<Account>
deleteAccount(username: string): Promise<null>
```

| Method | Route | Notes |
| --- | --- | --- |
| `login(username, password)` | `POST /v1/sessions` | The route ignores the bearer token, so any client can sign in. `token` is the new session; `expiresAt` is Unix seconds |
| `logout()` | `DELETE /v1/sessions` | Ends the session this client was built with (`204`) |
| `me()` | `GET /v1/sessions/me` | Needs a session token; the administrator token gets `401` |
| `changePassword(current, next)` | `POST /v1/accounts/me/password` | Needs a session token. Ends every session of the account, including this client's |
| `listAccounts()` | `GET /v1/accounts` | An array sorted by username |
| `createAccount(account)` | `POST /v1/accounts` | `201`; `409` when the name exists in any case |
| `getAccount(username)` | `GET /v1/accounts/{username}` | `404` when missing |
| `updateAccount(username, changes)` | `PATCH /v1/accounts/{username}` | A password reset, a role change or `enabled: false` ends the account's sessions |
| `deleteAccount(username)` | `DELETE /v1/accounts/{username}` | `204` |

```js
import { HubClient } from '@dixonsolutions/liveengine/hubs';

const admin = new HubClient('http://127.0.0.1:8787', { token: process.env.LIVEENGINE_TOKEN });
await admin.createAccount({ username: 'alice', password: 'correct-horse-battery', role: 'user' });

const { token } = await admin.login('alice', 'correct-horse-battery');
const alice = new HubClient('http://127.0.0.1:8787', { token });
console.log((await alice.me()).role); // "user"
await alice.logout();
```

Failures throw with `.status` like every other method, for example `401` with `invalid username or password`.

## Live connections

```ts fragment
interface Connection { id: string; hub: string[]; room: string; user: string; role: string; transport: string; connectedAt: number; remote: boolean; }

connections(filters?: { hub?: string; room?: string; user?: string }): Promise<Connection[]>
kick(id: string): Promise<null>
```

`connections` calls `GET /v1/connections` with the filters as query parameters; `kick` calls `DELETE /v1/connections/{id}`, which closes the socket with the code `kicked` (`404` when the id is not connected). Every key in `filters` becomes a parameter, so leave unused keys out instead of setting them to `undefined`. Details: [manage live connections](/guides/connections-admin).

```js
const [first] = await admin.connections({ hub: 'ranked-au', user: 'alice' });
if (first) await admin.kick(first.id);
```

## Live, discovery and pairing methods

| Method | Purpose | Guide |
| --- | --- | --- |
| `ticket(id, { userId, serverId, role = 'peer', credential, path = [] })` | Single-use room ticket: `{ ticket, url, expiresAt }`. A non-empty `path` uses the `ticket` route operation | [Live rooms](/guides/live-rooms) |
| `watchTicket({ path = [], depth = 1 })` | Read-only registry watch ticket: `{ ticket, expiresAt }` | [Live registry](/guides/live-registry) |
| `watchRegistry({ path = [], depth = 1, ticket, WebSocket, timeoutMs })` | Subscribe to the live registry; resolves with a `RegistryWatch` after the first snapshot | [Live registry](/guides/live-registry) |
| `discover({ kind = 'any', path = [], depth, requirements })` | `{ candidates }` of hubs and peers | [Find and pair](/guides/find-and-pair) |
| `pair({ subject, target = { kind: 'any' }, path = [], credential, waitMs })` | A descriptor `{ userId, link, room, ticket, url, transports }` for `LiveClient`; `waitMs` extends the request timeout | [Find and pair](/guides/find-and-pair) |
| `renewal(request)` | A `renew` function for `LiveClient` that pairs again | [Find and pair](/guides/find-and-pair) |
| `request(route, { method, body, signal, token, timeoutMs })` | Any authenticated route, for example `/v1/links`. `token` replaces the client's token for this call | [Hub links](/guides/hub-links) |

Hub-scoped provider credentials work with `route()` only; see [provider hosting](/guides/provider-hosting). `LiveClient`, `connectLive` and the browser helpers are exported by `@dixonsolutions/liveengine/live-client`; see the [live client reference](/node/live-client).

## Properties

| Property | Type | Notes |
| --- | --- | --- |
| `address` | `string` | Normalized base URL without a trailing slash |
| `timeoutMs` | `number` | Request timeout |
| `maxResponseBytes` | `number` | Response size cap |

The token is intentionally not a public property.

## Errors

| Error | Cause |
| --- | --- |
| `TypeError` | Invalid address, missing token, invalid limits, or non-array `args` |
| `Error: Incompatible hub protocol` | Contract protocol mismatch |
| `Error: Hub response exceeds configured limit` | Response exceeded `maxResponseBytes` |
| `Error: Hub returned invalid JSON (HTTP n)` | Non-JSON response |
| `Error` with `.status` | Non-2xx HTTP response |
| `AbortError` / timeout error | Request timed out or caller aborted |

```js
try {
  await client.list();
} catch (error) {
  if (error.status === 401) {
    console.error('check LIVEENGINE_TOKEN');
  } else {
    throw error;
  }
}
```

## Custom fetch

The `fetch` option is useful for tests, instrumentation, or a runtime-specific transport. It must match `globalThis.fetch` semantics.

```js
const client = new HubClient('https://hub.example', {
  token: 'test-token',
  fetch: async (url, init) => {
    console.log(init.method, url);
    return fetch(url, init);
  },
});
```

The client sets `redirect: 'error'`; a custom fetch should honor it.

## TypeScript

```ts
import { HubClient, HUB_PROTOCOL, type HubDefinition } from '@dixonsolutions/liveengine/hubs';

const definition: HubDefinition = {
  id: 'ranked-au',
  mode: 'internal',
  scopes: { region: 'au' },
};

const client = new HubClient('http://127.0.0.1:8787', {
  token: process.env.LIVEENGINE_TOKEN!,
});
await client.register(definition);
```

`call<T>` is generic so you can type application results:

```ts
interface Counter { count: number; }
const counter = await client.call<Counter>('counter', 'increment', [1]);
```
